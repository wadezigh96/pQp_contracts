## Requirement coverage and remaining work

1. **Canonical envelope: IMPLEMENTED / TESTED.** Strict domain-separated sorted ASCII JSON, full fixture fields including native chain IDs, identity/key reference, exact action, assets/decimals/mapping, both amounts, fees/slippage, recipient commitment, replay/policy/version/time/revocation/evidence/finality. Literal JS/Rust bytes/hash vector shared. Native predecessor is authentication; SHA-256 is not a signature. Generic JS callbacks are trusted dependency seams, not real crypto verifiers.
2. **NEAR actual authorization: IMPLEMENTED / TESTED locally.** Owner-pinned full profile; agent/router/policy/version/destination/action/recipient/both amounts/expiry/revocation/replay enforced. Legacy dispatch disabled, so the old JS dispatch builder is no longer an executable contract path. State-layout/API migration is NOT IMPLEMENTED and requires review before any deployment. Runtime network identity is owner-configured, not introspected.
3. **Durable replay and lifecycle: IMPLEMENTED / TESTED single-host prototype.** Atomic snapshot/lock persistence, independently unique nonce/intent indexes, CREATED/AUTHORIZED/SUBMITTED/CONFIRMED/SETTLED plus cancel/expiry/failure/reconciliation, pre-send reservation and immutable evidence references. Production distributed storage, crash/power-loss filesystem certification, executor integration and automatic refunds are NOT IMPLEMENTED. Proof callbacks and trusted orchestrator transitions do not supply consensus evidence.
4. **NEAR native adapter: IMPLEMENTED / MOCKED.** Exact unsigned Transfer preparation and synthetic receipt-tree consistency. Native transaction serialization, signer isolation integration, independent receipt/finality verification and execution are NOT IMPLEMENTED.
5. **Ethereum: IMPLEMENTED / MOCKED preparation only.** Chain IDs 1/11155111, native asset/decimals/amount/recipient, empty calldata, operator profile/mapping/fees; no production verifier or execution. Solidity remains a separate classical local policy contract, not a cross-L1 envelope consumer.
6. **BSC: IMPLEMENTED / MOCKED preparation only.** Separate 56/97 identities and finality profile, not Ethereum assumed safe. Parlia/BEP-126 proof verification and live execution are NOT IMPLEMENTED.
7. **Solana: IMPLEMENTED / MOCKED preparation only.** Independently configured full genesis, System Program transfer, exact instruction/account metas/signers, recent blockhash, last-valid block HEIGHT and u64 lamports. Native wire serialization, PDA/durable nonce/general programs and live finality are NOT IMPLEMENTED; unsupported paths reject.
8. **Zcash: EXISTING PARSER TESTED / JS INTEGRATION BLOCKED.** Pinned `zcash_address =0.13.0` parses real UAs in Rust; shielded receiver capability and no agent-authorized transparent fallback. Native JS preparation explicitly rejects Zcash pending parser/wallet integration. No scanner, shielded transaction construction/signing/broadcast, nullifier/witness/finality verification or shielded receipt proof is implemented. Active ZIP-316 revision must not be confused with draft Revision 2.
9. **Adversarial behavior: TESTED at local seams / live gaps explicit.** Mutation/replay/substitution/forgery/malformed response/mock finality/reorg/partial/timeout/duplicates covered. Production consensus attacks, real chain reorganizations and external failure recovery were NOT RUN.
10. **Privacy: MINIMIZED, NOT PRIVATE.** NEAR emits authorization commitment/nonce/policy-version evidence without raw recipient or amount in the event, but calldata and policy storage remain public. Local state retains essential evidence references. Native recipient commitments are deterministic and dictionary-searchable; metadata/amount/timing/account correlation remain. No private NEAR/EVM layer or private agent transport exists.
11. **Quantum: NOT IMPLEMENTED.** Classical native authorization only; no PQ/hybrid signatures/KEM, migration implementation, downgrade protection, recovery or tested PQ claims. Hashes/nonces are not PQ authentication.
12. **Documentation/demo/security: UPDATED.** Canonical spec, adapters, architecture, threat/privacy/PQ boundaries, operations/deploy prerequisites and this traceability. Local tests are the reproducible no-wallet demo; no fabricated production demo.
